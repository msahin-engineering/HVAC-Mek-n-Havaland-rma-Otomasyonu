# HVAC-Mek-n-Havaland-rma-Otomasyonu
Siemens S7-1200 PLC, TIA Portal ve Factory I/O kullanılarak geliştirilen, ortam sıcaklığına göre 6 fanın kademeli olarak devreye alındığı, fan hızlarının kontrol edildiği ve sıcaklık durumlarının sinyal lambalarıyla gösterildiği HVAC havalandırma otomasyonu projesi.
